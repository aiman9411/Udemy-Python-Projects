# Guess the State Game

## Overview
"Guess the State Game" is a simple, interactive geography quiz game built using Python's Turtle graphics library. The game presents a blank map of the United States, and players are prompted to guess the names of the states. Each correct guess results in the state name being labeled on the map. The game continues until the player decides to exit or completes all 50 states.

## Features
- Interactive GUI using Turtle graphics.
- Real-time state name input and verification.
- Score tracking showing the number of correctly guessed states.
- Ability to see your final score after the game ends.

## Prerequisites
Before you can run the game, you need to have Python installed on your computer. Python can be downloaded from [here](https://www.python.org/downloads/). This game is compatible with Python 3.x.

Additionally, you'll need the following Python library:
- `pandas`: Can be installed via pip:
  ```
  pip install pandas
  ```

## Installation
To run the game, clone this repository to your local machine:

```bash
git clone https://github.com/yourusername/guess-the-state-game.git
cd guess-the-state-game
```

## Usage
To start the game, run the `main.py` file:

```bash
python main.py
```

The game interface will open in a new window. Follow the on-screen prompts to guess the names of the states. Type your guess into the input box and press `Enter` or click `OK`.

## Game Rules
- The game asks you to name states one at a time.
- Each correct guess will be labeled on the map at the appropriate location.
- The game tracks the number of correct guesses and displays this count at the top of the window.
- The game ends when you either guess all 50 states correctly or close the game window.
