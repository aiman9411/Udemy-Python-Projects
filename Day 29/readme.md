# Password Generator Application

This Password Generator Application is designed to create secure and random passwords based on user-defined criteria. It also allows users to save their generated passwords along with associated website and email information securely in a text file. This application is built using Python's Tkinter library for the graphical user interface.

## Features

- **Generate Random Passwords:** Securely generate passwords with a mix of letters, numbers, and symbols.
- **Save Password Information:** Save password along with the associated website and email information.
- **GUI Based Application:** Easy to use graphical interface.
- **Data Persistence:** Saves all the password data locally in a text file.

## Prerequisites

Before you run this application, make sure you have Python installed on your machine. Python 3.6 or higher is recommended. You can download it from [python.org](https://www.python.org/downloads/).

## Installation

Clone this repository to your local machine:

```bash
git clone https://github.com/yourusername/password-generator.git
cd password-generator
```

## Usage

To run the application, navigate to the cloned directory and run the following command:

```bash
python password_generator.py
```

### Generating a Password

1. Click on the "Generate Password" button to automatically generate a new password.
2. The generated password will appear in the Password field.

### Saving Password Information

1. Enter the website and email/username associated with the password.
2. Click on the "Add" button.
3. Confirm the details in the popup window to save the information to `data.txt`.
